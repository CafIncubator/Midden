# Support

Midden is maintained as a research-focused open-source project. Choosing the right channel helps
maintainers and other users respond effectively.

## GitHub Discussions

Use [GitHub Discussions](https://github.com/CafIncubator/Midden/discussions) for:

- Help using or configuring Midden
- Questions about running the CLI or deploying the web application
- Sharing research workflows and examples
- Exploring an idea before its requirements are clear
- General questions that may help other users

Use the Q&A category for questions and the Ideas category for early proposals. Search existing
discussions before starting a new one, and mark an answer when it resolves the question.

## GitHub Issues

Use [GitHub Issues](https://github.com/CafIncubator/Midden/issues) for:

- Reproducible defects
- Defined feature proposals with a clear research or user need
- Specific documentation corrections
- Bounded implementation work

Complete the relevant issue form and remove credentials, private URLs, identifying research
data, and other sensitive information from logs and screenshots.

## Private reports

- Report security vulnerabilities through the private route in [SECURITY.md](SECURITY.md).
- Report Code of Conduct concerns through the private route in
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Never use a public issue or discussion for either type of report. Midden does not provide private
technical support; private channels are reserved for security and conduct reports.

## Response expectations

Midden is community-supported. Maintainers and other users respond to questions, issues, and
feature requests as availability and knowledge permit. The project does not guarantee a response,
resolution, or support timeframe. Opening an issue does not guarantee that the requested work
will be accepted.

Security reports follow the response targets in [SECURITY.md](SECURITY.md). Conduct reports are
reviewed as promptly as maintainer availability permits, without a fixed response target.
